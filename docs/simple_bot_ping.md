# Бот Mr.Pong (`simple_bot_ping`)

`simple_bot_ping` — это групповой чат-бот для MeshCore. Он не является
репитером и не пересылает пакеты: бот подключается к каналам, отвечает на
сообщения и ведёт статистику по репитерам и путям.

Текущая версия в исходниках: **Bot v1.7.3 @1.18.0** (сборка 07-11-2026).
Основной вариант сборки — LilyGo T-Echo (e-ink).

## Сборка

Бот не входит в наборы `build.sh` (`build-companion-firmwares`,
`build-repeater-firmwares` и т.д.) — его нужно собирать явно:

```bash
export FIRMWARE_VERSION=v1.18.0
sh build.sh build-firmware LilyGo_T-Echo_bot_ping
```

Или напрямую через PlatformIO:

```bash
pio run -e LilyGo_T-Echo_bot_ping
```

Env `LilyGo_T-Echo_bot_ping` наследует `LilyGo_T-Echo`: nRF52, SX1262, e-ink
дисплей, GPS и BME280. Дополнительно заданы `MAX_CONTACTS=350` и
`MAX_GROUP_CHANNELS=40`.

## Радио и путь

Бот задаёт радио-параметры **у себя в `MyMesh.h`**, а не берёт их из глобальной
секции `[arduino_base]`:

| Параметр | Значение |
|---|---|
| `LORA_FREQ` | `868.856` МГц |
| `LORA_BW` | `62.5` кГц |
| `LORA_SF` | `7` |
| `LORA_CR` | `6` |
| `LORA_TX_POWER` | `22` dBm |
| `PATH_HASH_MODE` | `2` байта |

`PATH_HASH_MODE` используется для собственных сообщений бота (объявления
репитеров, `post`). Ответы на сообщения в каналах отправляются с тем же
размером path hash, с которым пришло входящее сообщение.

Если нужно изменить радио-параметры бота, правьте `MyMesh.h`: глобальные
`LORA_*` из `platformio.ini` на бота не влияют.

## Формат сообщений

Бот разбирает только сообщения вида:

```text
<отправитель>: <текст>
```

Сообщения без `: ` игнорируются. Для команд (кроме `ping`/`test`) в тексте
должно быть имя **`Mr.Pong`**; эмодзи в имени не обязательна.

Пинг-ответы:

- прямой или zero-hop пакет → `@[отправитель] диpeкт c SNR …dB и RSSI …dBm`;
- flood/через репитеры → `@[отправитель] N хопов c <первый репитер>: <путь>`,
  где путь — hex-префиксы; если path hash не 2 байта, добавляется
  `‼️дaвaй 2 бaйтa!`.

одном сообщении: ответ может быть от последнего совпавшего блока. Регистр
соблюдается не для всех триггеров — используйте варианты из таблицы.

## Ограничение частоты и quiet

- Между ответами бота — не меньше **5 секунд**. Слишком частый ответ
  подавляется и увеличивает `ignores`.
- Если в `#bot` пришло **30 сообщений за 5 минут**, включается quiet:
  бот перестаёт отвечать. Флаг пересчитывается при новых сообщениях в `#bot`;
  после спада трафика ответы возвращаются. Перезагрузка сбрасывает quiet.
- Serial-команда `quiet` принудительно включает quiet. Отдельной команды
  «выключить quiet» нет.
- В `Public` ответ на ping/test дополнительно ограничен 5 минутами.

## Статистика и обслуживание

Счётчики хранятся в `/node_stats` и переживают перезагрузку:

- запросы (сколько раз бот должен был ответить);
- отправленные и полученные сообщения;
- благодарности и подавленные ответы;
- суммарные хопы, максимальный путь, число известных репитеров.

Статистика сохраняется на флеш не чаще раза в 10 минут (если была изменена),
а также при `reboot`, `shutdown`, `stats reset` и автоматической перезагрузке.

После **1000 отправленных сообщений** бот при валидных часах и после 03:00
сохраняет статистику и перезагружается. Это защита от накопления состояния и
утечек; для обычной работы ничего делать не нужно.

## Репитеры

Бот автоматически добавляет репитеры из адвертов, если имя похоже на
стандартное (`ABC-…`, `ABC_…` или `LO-ABC-…`). Полный ключ ищется первым,
затем префиксы 3 и 2 байта. Когда таблица заполнена (`MAX_CONTACTS=350`),
самый давно обновлённый репитер перезаписывается.

- Новый или изменившийся репитер объявляется в `#bot`, если бот работает
  больше 24 часов.
- Старые репитеры удаляются, если адверта не было 14 дней и репитер не
  наблюдался 7 дней. Проверка запускается не чаще раза в 5 часов.
- Префиксы из путей сообщений, которых бот не знает, создают
  `UnknownRepeater` и учитываются в статистике.
- `Mr.Pong <4 hex>` показывает информацию по 2-byte префиксу.
- Serial-команда `repeaters` печатает полный ключ, имя и счётчик.
- Serial-команда `remove <prefix>` удаляет репитер по 2-byte префиксу.

## Часы и GPS

- Валидное время — примерно с 2026-01-01 до 2030-12-31 (константы
  `MAGIC_TIME_1`/`MAGIC_TIME_2`).
- При первом валидном сообщении бот берёт время из timestamp отправителя.
  Затем периодически (каждое 5-е сообщение) подправляет часы, если разница
  меньше часа.
- При включённом GPS и наличии фикса время берётся из GPS.
- `gps sync` включает GPS, сбрасывает провайдер и запрашивает синхронизацию.
- `gps on`/`gps off` включают/выключают GPS, `gps` показывает состояние и
  количество спутников.
- При включённом GPS синхронизация запрашивается раз в 1 час 10 минут.
- `time <epoch>` на serial выставляет время и отключает GPS-синхронизацию.

## Serial-команды

| Команда | Действие |
|---|---|
| `post <text>` | Отправить сообщение в `#bot` от имени бота. |
| `clock` | Показать текущее время UTC. |
| `quiet` | Включить quiet. |
| `time <epoch>` | Установить время; GPS-синхронизация отключается. |
| `import meshcore://…` | Импортировать контакт/карточку. |
| `remove <prefix>` | Удалить репитер по 2-byte префиксу. |
| `ver` | Показать версию. |
| `reboot` | Сохранить статистику и перезагрузиться. |
| `gps` | Показать состояние GPS. |
| `gps on` / `gps off` / `gps sync` | Управление GPS. |
| `stats` | Подробная статистика в serial. |
| `stats reset` | Удалить `/node_stats`, сбросить счётчики и перезагрузиться. |
| `repeaters` | Список известных репитеров. |
| `shutdown` | Сохранить статистику и выключить питание. |

Команды обрабатываются построчно; поддерживаются `CR`, `LF` и `CRLF`.
Слишком длинная строка не обрезается и не выполняется — выводится
`ERROR: command too long`.

## Экран

На T-Echo бот показывает:

- логотип MeshCore и напряжение батареи;
- `Mr.Pong in #bot`;
- строку вида `Q0 R1 S2 L3`:
  - `Q` — quiet,
  - `R` — requests,
  - `S` — sent,
  - `L` — сообщений в `#bot` за последние 5 минут;
- время UTC и состояние GPS (`GPS fix`/`GPS no fix`, число спутников).

E-ink обновляется раз в 10 секунд; раз в 60 секунд делается полная
перерисовка для восстановления контраста. На T-Echo автоотключение экрана
выключено (`AUTO_OFF_MILLIS=0`); кнопка пользователя включает экран.

## Ограничения

- Бот не пересылает пакеты и не работает как репитер.
- Поддерживаются только групповые каналы; личные сообщения, ACK и запросы
  контактов не обрабатываются.
- Каналы и их PSK жёстко зашиты в `MyMesh.h`; управлять ими через CLI нельзя.
- Команды — это поиск подстрок; несколько триггеров в одном сообщении могут
  дать неожиданный ответ.
- Любой узел, знающий PSK канала, может отправлять команды боту; отдельной
  авторизации нет.
- Радио-параметры бота заданы в `MyMesh.h` и не наследуются из
  `[arduino_base]`.
